# DP018 Native Joint Fixture (WIP)

This is an implementation-stage host fixture, not final acceptance. It compiles
complete extracted DP probe/pdata/remove/init/exit and S/N callback definitions,
plus real SSDK030 ready/mark/cache/notifier/G3 and the real PHY mapper body.
Kernel structs and platform/notifier/RTNL/refwait, HAL and hardware leaves are
explicit checked host models, not Linux execution or an object ABI proof.

The runner reuses the bound017 and frozen030 prepared source text. Only018 is
derived through exact old/new hunk coordinates and complete context; no package
is rebuilt or repeatedly prepared. Live selected inventories, source trees and
owned test assets are checked at the end. Saved source qualification is limited
to the explicit checks the runner actually performs, not an atomic lock.

HSL property enum/type and the full property array come from actual SSDK source:
EXCL_CPU is2 and BUTT is5. Old handwritten1/2 values are not reused. The metadata
and OS struct initialization in the host model is synthetic and does not prove
FAL/hardware-wide readiness. Producer mark and query themselves are actual C.

`--matrix smoke` is only the initial connection check. `--matrix stages` adds
the initial stage matrix. `--matrix joint` is the full accepted default-prestate
host matrix. `--matrix bounded` remains a subset excluding prelist/veto/veto-reader
positives; it is not sufficient for final host qualification. Original r13 FAIL
under the unsupported allocation-owner assumption is retained, not regraded.

The bounded campaign consumes complete installed ssdk_init.h/FAL/ref headers
and actual SDK scalar typedefs, with OS-only shims, across MAC_POLL/SWDEV off/on.
The actual source include/profile clauses are compiled and preprocessed. Four
nonselected source CPP projections preserve tokens/order, normalizing only the
known braces around the unchanged platform-error log. This is not a target
header graph, kernel module build, modpost/export/link or runtime ABI proof.

Current functions include the real G3 scalar/table mapper and provider bitmap
getter; PHY addresses are deliberately nonidentity and no-match is tested.
Bus-index lookup is still an explicit single-bus model. I2C alternatives, mapping
table destruction, arbitrary PHY detach and complete bus/root lifetime are OPEN.
Namespace list publication/removal and by-name acquisition share refs_mutex.
The pthread model implements the recorded unlock/refwait boundary for both
DEBUG_NET_SMALL_RTNL configurations, not actual Linux RCU or kernel execution.

Callbacks dispatch through the actual registered function-pointer ledger. The
actor is a deterministic scheduling injection after modeled registration unlock
and before real probe bookkeeping returns; it is not a real RTM_NEWLINK/netifd
process. Actual STP/filter state and independent ethtype state are exercised.
G3 parks in the real mapper delegation before its final PHY-field access.
Atomic/blocking drain tests hold a modeled framework reader/RTNL after a real
foreign callback returns; they do not claim a parked native hardware operation.
Empty lower-device iteration/topology and its atomic-context safety remain OPEN.

Q01 checks actual implementation owner bits, common_init_done and nss_dp[] as
well as framework flags/dpc pointers; separate runtime mutants delete each clear.
Q02 separates provider software mapping, HW binding value and DP node/call ledger,
under fresh successful SDK default prestate and no concurrent FAL writer. Device0
native ports use actual port-1 defaults; other cells are foreign sentinels. A
same-value DP fal_set is not allocation/ownership transfer. Successful-port remove
must invalidate exactly once; failed probe must preserve this admitted prestate.
free_netdev never erases the ledger or restores HW state. Wrong-argument, missing
successful-clear and erroneous abort-invalidation negatives remain exact. This
contract is source-backed and parent-approved, not tuning the old model to green.
An omitted required same-value set also fails the exact call/phase assertion;
HW equality alone never qualifies it. HW terminal value and software mapping are
asserted separately. Provider-init bodies saved for provenance are compiled:false
and are not executed or represented as a successful HW initialization run.
Invalid-after-remove/reprobe, HW/software mismatch, partial failing setters and
concurrent writers are OPEN; no generic recovery/restore policy is proved.

Every positive uses an independently specified complete trace, exit0 and empty
stderr. Warnings other than unused fixture functions/parameters are errors.
Compiler failure, timeout, sanitizer output and generic nonzero are failures,
not runtime negative-control success. Raw streams and commands are preserved.
ASan canary sets both runtimes' exitcode97, UBSan canary both98; the normal body
sets both97, with no recovery. Both actual env strings are recorded per command
(Darwin shares the runtime exit setting). Driver semantic failures use86. LSan is
disabled on this host and is not qualified. Existing unsigned PHY-ID to char
API adaptation is explicit and host-only; actual source bodies/signatures stay
intact. No unused-variable/unused-but-set suppression is enabled.

Source reuse verifies fixed receipt identities, exact pins and archive-member
manifests, all DP first17/SSDK18 patch hashes and complete before/after hash
chains against live inputs. The complete018 output tree is derived from that
expected DP17 map, not captured from the output under test. No old executable
or preparation program is run. The two exact recipe paths alone may change the
single PKG_RELEASE8 line to9; normalized bytes must match their explicit receipt
hashes. Actual/baseline hashes and release delta are recorded per new run, with
exact end-input checks. No recipe is edited by this test, and no old8 result is
upgraded to9. Other input changes remain rejected.

Only the native normal strong-provider profile is in scope. Generic PHY/DSA,
override handback, forced unload, SSDK root partial-init/error propagation,
FW/DMA/HW idle, target builds/devices and performance remain OPEN.
