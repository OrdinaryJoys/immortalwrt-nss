# Actual root exit order: serial host fixture

The exact31/r3 ssdk_init.c SHA b8041a72 is input-bound. Its complete actual
regi_exit definition, including chip/SFP guards, registration predicate, error
logging and platform/private tail, is extracted without body modification.
SDK uint32/bool/error declarations and device capacity come from that receipt's
real headers. Linux __exit, private structs, producer/cleanup/platform/log leaves
are explicit models, not target ABI or real driver retirement.

Twelve chip/SFP profiles cover DESS/HPPE/ISISC/ISIS/MP/no-chip and SFP on/off.
Each runs26 fixed input scenarios: every0..3-device registration mask with no
errors, plus distinct single/multiple cleanup errors on the all-registered mask
for each applicable count. All312 case traces are compared byte-for-byte with an
independent Python oracle, including every error and the earliest error summary.
The model requires all peer driver/registered-switch producers stopped before
any SFP or cleanup; SFP-all before cleanup; all cleanup before platform; complete
platform/private tail even on errors. Empty/foreign peers are not retired.

Six fixed source mutants cover old per-device interleaving, early SFP retirement,
missing cleanup, overwritten first error, early platform exit and ignored
registered predicate. Each is newly compiled cleanly, then must exit86 with no
stdout and exactly one fixed ROOT_ASSERT line. No compile error, timeout,
sanitizer exit or generic nonzero is credited. Host serial barrier checks are not
threads, actual driver drain, notifier/IRQ/workqueue completion or FW quiescence.
regi_exit remains void: recording errors does not prevent real module unload.

--sanitize enables ASan/UBSan with actual97/98 canaries and equal per-probe option
exitcodes; LSan is disabled/unverified. -O Python, fixed inventories, source and
four asset hashes, compiler identity and exact generated bytes/paths are checked.
One positive binary per profile runs all26 cases, avoiding per-case compilation
and output-file expansion. Source/recipe/prepare helper and previous lock tests
are not edited or executed. Full31 preparation and real root ownership/drain are
separate parent evidence, not inferred from these host counts.

the typedef matcher required one space where the actual header has three.
That failed record is retained; r2 uses the exact declaration with flexible whitespace.
