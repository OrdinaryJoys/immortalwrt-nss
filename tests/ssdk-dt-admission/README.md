## Oracles and ownership

Python independently predicts complete MODEL actions/owners/arguments/fields.
This is not every original formatted driver log. C validates vector identity,
live/kind/count/size before indexing, then every cfg allocation identity/shape,
uniqueness and seen closure before reading any payload. Same-valued all-disabled
and fallback objects therefore cannot hide swap/alias/missing/offset owners.
These are precise runtime source negatives. A separate MODEL quality control
pollutes only the ledger's recorded cfg byte-size: the shape gate rejects it,
and removing only that gate allows the same payload/full trace. This is not a
production bug or actual short allocation, and does not claim full trace alone
would incorrectly accept a slot swap. No isolated removed-admission-gate
counterfactual acceptance is claimed; independent return/trace gates can also
reject those states.
Node references track second find's from-consumption, disabled/missing cleanup,
temporary ownership, adoption, borrowing, exit and repeated exit. Original
property contents remain unchanged; the mutation model swaps property pointers
and retains old storage rather than overwriting a borrowed string buffer.
After each successful parser call, the complete selected-branch reduced cfg
is compared: admitted ID/node/access, emulation from original or replacement
bool, tm/bm tick writes, opaque clock token, error-clock initialization, chip
initial state and untouched fields. The clock leaf returns a distinguishable
opaque token, not a real clock reference. Four precise mutants delete selected
emulation/tm/bm/clock stores while preserving the earlier modeled action trace.

Oldraw uses a complete old parser plus an instrumented fail-fast raw-ID API
boundary BEFORE any unsafe scalar decode/index. It is a safe old-entry boundary
witness, not reproduction of a real OOB/crash or proof of old runtime behavior.
Compiler errors, signals, sanitizer diagnostics and timeout never count as
semantic negatives. Each credited control must compile clean and return86 with
empty stdout and exactly one expected SSDK_DT marker. Output pollution controls
are separate. Clang has activation canaries97/98; normal cases use exit97 for
